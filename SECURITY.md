# Security Policy

## Reporting

If you discover a security issue in BIJOTEL, please report it responsibly.

**Email:** contact@aisophical.com
**Subject:** [SECURITY] BIJOTEL report

Please include:
- Description of the issue
- Steps to reproduce
- Impact assessment

We will acknowledge receipt within 48 hours and provide a timeline within 7 days.

## Scope

- BIJOTEL Python package (pip install bijotel)
- HMAC chain integrity
- Policy engine
- API authentication
- Export verification

## Supported Versions

| Version | Supported |
|---------|-----------|
| 2.x     | Yes       |
| 1.x     | Critical fixes only |
| < 1.0   | No        |
